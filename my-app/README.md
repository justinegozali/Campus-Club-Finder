Campus Club Finder

A React web application to help students discover and join campus clubs.

🌟 Features

View a list of campus clubs with sorting and layout toggle

Club detail pages with event list and join button

Join status stored in localStorage

404 page for invalid URLs

🧱 Tech Stack

React with React Router

Tailwind CSS for styling

LocalStorage for persistent join state

Vite (or Create React App) as the dev environment

🧭 Pages

/ — Home Page

/about — About Us

/clubs — Club List

/clubs/:clubId — Club Details

* — 404 Not Found
